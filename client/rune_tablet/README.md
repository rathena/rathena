# Rune Tablet client data

Client files shipped with the Rune Tablet patch, kept unchanged for deployment.
Server side and protocol: `doc/rune_tablet.txt`.

| File | Content |
|---|---|
| `pre-re/System/Rune/*.lub` | **Installed** pre-renewal tables: the seven numeric TWRoZ lubs (2026-05-06 live) as shipped, plus English `rune_desc.lub`/`runeset_desc.lub` generated by `tools/rune_tablet/export_db.py`. Source of `db/pre-re/rune_tablet_*.yml` |
| `System/Rune/*.lub` | kRO 2026-03-04 rune tables (compiled Lua 5.1), the source of `db/re/rune_tablet_db.yml` and `db/re/rune_tablet_decomposition.yml` |
| `SystemEN/itemInfo_RuneTablet.lua` | `tbl_runetablet`: 62 English iteminfo entries (27266-1002482) for the reward boxes and cards missing from the English iteminfo |

Pre-renewal servers (PRERE) use `pre-re/`: install those lubs into both
`System/Rune` and `SystemEN/Rune`, add the 364 TWRoZ rune textures and the Goblin
Coin Fragment icon as loose files, and add English entries for the seven pre-renewal
items to the client's iteminfo. See `doc/rune_tablet.txt` section 10.

The live 2025-07-16 client ships its own decompiled `System/Rune` lubs. They
list a subset of the server data: Rune Sets 1260045 and newer (Chapter 1) and
fragments 1263093 and newer are missing, so those sets stay invisible in the
window. These lubs are untested with the 2025-07-16 executable. Back up the
client's `System/Rune` folder and check the Rune Tablet window, including the
category tabs, before replacing it.

`tbl_runetablet` is a separate table: merge its entries into the client's
`tbl` in `System/itemInfo*.lua`, or load it from there. Keep the encoding of the
client's iteminfo (Korean clients use EUC-KR/CP949). The Chapter 1 and Episode 19/20 monsters (21520-23060) additionally
need their sprites and names in the client data.
